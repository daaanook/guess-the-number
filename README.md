# Guess the Number

Small console game I made while learning Python.
The computer picks a random number and you have to guess it in a limited number of tries.

## How to play

```
python3 game.py
```

Choose a level (easy / medium / hard), then type your guesses. The game tells you if the number is higher or lower.

## What I learned

- functions
- while loops, continue / break
- dictionaries and tuples
- checking user input (isdigit)
